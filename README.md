# sample

GitHub実務フロー練習用のリポジトリ。

## ブランチ運用

| ブランチ | 役割 |
| --- | --- |
| master | 本番相当。リリース時のみ更新する |
| develop | 開発の統合先。作業ブランチはここから切る |
| feature/* | 機能追加 |
| fix/* | バグ修正 |
| hotfix/* | 本番の緊急修正。masterから切る |

## コミットメッセージ

`[種別] 内容` の形式で記述する。

- `[Add]` 追加
- `[Fix]` 修正
- `[Update]` 変更
- `[Remove]` 削除

## 開発の流れ

1. Issueを起票する
2. developから作業ブランチを切る
3. コミットしてpushする
4. developへPRを出す
5. レビュー後にマージし、ブランチを削除する
